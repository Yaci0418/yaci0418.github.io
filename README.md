# yaci大神 · 夏日来信

二次元风格个人主页，使用原创动漫插画、樱花粉和天空蓝配色。

网站：https://yaci0418.github.io/

## 本地预览

运行 `python3 -m http.server 4173`，打开 http://localhost:4173 。无需安装依赖或构建。

## 内容编辑

- `index.html`：个人介绍、作品与页面结构
- `style.css`：响应式样式、主题配色
- `app.js`：随记内容、主题切换和阅读弹窗
- `assets/summer-letter.jpg`：原创 AI 插画
- `ARTWORK.md`：插画生成提示词

页面支持手机适配、明暗主题、键盘导航和随记阅读。短随记为本站创作内容，不是个人履历。Google Fonts 不可用时自动回退到系统字体；无分析脚本或后台服务。

## GitHub Pages

Settings → Pages → Deploy from a branch → main → /(root) → Save。无需填写自定义域名。

修改提交到 main 后，GitHub Pages 会重新发布。官方指南：https://docs.github.com/en/pages/quickstart
